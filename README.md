# Rooftop Rumble · Test Supply

The latest **test version** of Rooftop Rumble. In the game, **Settings → Experimental settings → Beta test** loads it.

- `src/` holds the source files of the test version, in the order listed in `src/manifest.json`.
- The game server reads `src/manifest.json`, joins the files together and shows the result as the beta.
- `index.html` is the same thing already joined, so you can open it directly.
